KARAOKE STUDIO - VERSÃO 1.0

Recursos:
- Escolher um playback de áudio no celular
- Cantar enquanto o playback toca
- Gravar a voz pelo microfone
- Ouvir a última gravação
- Salvar automaticamente em Música/Karaoke Studio
- Visual claro com microfone e botões azuis

Observação: esta primeira versão grava a voz do microfone. Ela ainda não mistura o
playback diretamente dentro do arquivo final nem possui salas e perfis sociais.

Projeto Android nativo em Java. Requer Android Studio/SDK 35 para gerar o APK.
