# Como cadastrar músicas

1. Envie o arquivo de playback autorizado para esta pasta `catalog` no GitHub.
2. Abra `catalog.json` e adicione uma música neste formato:

```json
[
  {
    "title": "Nome da música",
    "artist": "Nome do cantor",
    "audioUrl": "https://raw.githubusercontent.com/jeremiasbritto-gif/karaoke/main/catalog/playback.mp3",
    "lyrics": "Primeira linha da letra\nSegunda linha da letra"
  }
]
```

Use somente playbacks e letras próprios, de domínio público ou que você tenha autorização para disponibilizar.
